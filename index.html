本应用已内置 PWA 原生应用清单（Manifest）、高分辨率矢量光圈应用图标（180/192/512px）、刘海屏安全区适配与 Service Worker 离线缓存内核。只需将下载的 index.html 文件上传到 GitHub Pages 或 Cloudflare Pages，即可在四端安装为无浏览器边框、永久不过期、支持完全断网运行的独立程序：

🍎 iOS / iPadOS（iPhone & iPad）

  1. 用系统自带 Safari 浏览器打开应用网址；
  2. 点击底部（iPad 为右上角）的 「分享 ⬆️」 按钮；
  3. 向下滑动并点击 「添加到主屏幕（Add to Home Screen）」；
  4. 桌面将生成带金色相机光圈图标的 Gear Studio 独立 App，全屏运行且支持 iPad 分屏与飞行模式离线使用。

💻 macOS（MacBook / Mac Studio）

  1. 用 Mac 自带 Safari 打开应用网址（注意需为 https:// 网址，本地 file:// 菜单会呈灰色）；
  2. 点击顶部菜单栏 「文件（File）」→「添加到程序坞 / 加入 Dock 中…」；
  3. 点击「添加」后，程序坞（Dock）与启动台（Launchpad）中将出现独立 macOS 桌面应用窗口，支持 Cmd + Tab 独立切换。

🪟 Windows 10 / Windows 11

  1. 用系统自带 Microsoft Edge 或 Chrome 打开应用网址；
  2. 点击地址栏最右侧的 「安装应用（Install App ⊕）」 图标；
  3. 确认后将生成独立无边框 Windows 窗口，自动创建桌面图标与开始菜单快捷方式，可固定到任务栏。
