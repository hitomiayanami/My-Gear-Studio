## ✨ 核心功能模块一览

### 1. 四维光学与人体工学互补引擎

基于个人器材库物理参数与实际拍摄逻辑，围绕以下四个维度生成 Top 3 合理方案，并附带 **FOMO 兜底建议**、**实地破局技巧**与 **季节日落光线衰减提醒**：

- **🌓 昼夜光圈与画幅接力**：白天携带 `OM System PEN E-P7 + 14-42mm EZ`（430g）口袋随拍，深秋/初冬 16:30 入夜后无缝切换 `Sony α6700 + Viltrox 25mm F1.7 Air` 或 `OM 17mm F1.8 II` 暗光大光圈。
- **🎒 跨机身轻重物理分工**：口袋随手抓拍机（≤ 470g）与背包高画质/远摄主力机并行，标明预估换镜次数与单机多镜防尘袋提示。
- **🔭 焦段边界与数码裁切延伸**：等效焦段标尺自动绘制 `α6700` 清晰影像缩放（1.5×）与 `E-P7` 2× 数码远摄转换器的虚线延伸区间。
- **🚗 不考虑便携 · 自驾/星空全画质旗舰模式**：一键解除重量惩罚，自动启用 `Fotopro X-4CS II + 42QJ` 碳纤维三脚架与多镜全覆盖组合。

### 2. 暗夜红光护眼速算器 & 反向灵感盲盒

- **🔴 暗夜红光护眼速算器**：全黑底暗红文字不破坏暗视力，支持一键带入当前方案最广焦段，自动计算 **星空银河防拖尾 300/400 法则快门上限** 与 **ND8 / ND64 / ND1000 减光慢门目标时间**，内置 B 门倒计时提示音秒表。
- **🎲 器材反推今日拍摄命题盲盒**：选定手边想带出门的一支镜头，反向生成 3 个专为该镜头光学脾气定制的街头/光影挑战任务。

### 3. 全球国家与省份路书库（Global Roadbook）

- 内置涵盖 **日本、中国（按省/直辖市细分）、韩国、新西兰、泰国、老挝、越南、新加坡、法国、意大利、捷克、挪威、英国、冰岛、美国、加拿大、秘鲁、约旦** 等地的精选拍摄基因预设。
- 支持**新增、编辑与删除**私人目的地预设，并可自由手写任意新国家或中国省份。

### 4. 多站跨城行程统筹 & 去重合并打包总清单

- 支持将单日快照（`Day 1 / Day 2…`）或跨城多站点串联，自动求解整趟行程的最大公约数底盘，生成**出发前总行李箱去重合并装包清单**与**逐站随身带走 vs 酒店留守核对单**。

## 📲 四端独立应用安装指南（PWA）

1. **自定义应用图标**：将你喜欢的方形头像/相机插画命名为 **`icon.png`** 上传至 GitHub 仓库根目录（与 `index.html` 并列），或在应用第 4 标签页直接点击「🖼️ 上传自定义应用图标」后导出 `index.html` 覆盖上传。
2. **🍎 iOS / iPadOS（iPhone & iPad）**：使用系统 **Safari** 打开网页 → 点击「分享」→ **「添加到主屏幕」**，支持 iPad 分屏与飞行模式完全离线使用。
3. **💻 macOS**：使用 **Safari** 打开网页 → 顶部菜单栏点击 **「文件」→「添加到程序坞 / 加入 Dock 中…」**，生成独立桌面应用窗口。
4. **🪟 Windows 10 / 11**：使用 **Edge** 或 **Chrome** 打开网页 → 点击地址栏右侧 **「安装应用」** 图标。

## 🔗 跨端数据同步说明

所有自定义修改均保存在当前设备的浏览器本地存储（`localStorage`）中，保障 100% 离线可用与隐私安全。如需在 Mac、iPhone 与 iPad 之间同步记录，可使用第 4 标签页提供的两种方式：

1. **跨端同步短链（推荐）**：点击 **「🔗 生成跨端同步链接」** 复制链接，发送至手机/平板 Safari 打开即可一键「合并新增项」或「全量覆盖」。
2. **全量 JSON 备份 / 独立 HTML 导出**：支持一键导出 JSON 备份文本或内嵌全部个人数据的独立 `index.html`。
