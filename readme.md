# 📷 Gear Decision Studio · 私人摄影器材与全球路书决策台

一个零外部依赖、纯离线运行、支持 **iOS / iPadOS / macOS / Windows** 四端安装为原生级独立应用的私人摄影出装决策与全球路书工具。

---

## ✨ 核心功能亮点

### 1. 四维光学与人体工学互补引擎
基于个人器材库物理参数与实际拍摄逻辑，自动过滤焦段冗余与头重脚轻的搭配，围绕以下四个维度生成 Top 3 合理方案：
- **🌓 昼夜光圈与画幅接力**：例如白天携带 `OM System PEN E-P7 + 14-42mm EZ`（430g）轻便变焦，入夜无缝切换 `Sony α6700 + Viltrox 25mm F1.7 Air` 暗光大光圈。
- **🎒 跨机身轻重物理分工**：口袋随手抓拍机（≤ 470g）与背包高画质/远摄主力机并行。
- **🔭 焦段边界实质拓宽**：超广角（`10-18mm F2.8`）与中长焦/一镜走天下（`18-300mm` / `40-150mm R`）协同扩展视角。
- **🎨 光学风格与创意互补**：标准现代镜头与复古老镜（`PENTAX S-M-C Takumar 50mm F1.4`）、移轴创意镜头（`TTArtisan 35mm F1.4 Tilt`）搭配。
- **🚗 不考虑便携 · 自驾/星空全画质旗舰模式**：支持一键解除重量限制，自动解锁重型碳纤维三脚架与多镜全覆盖组合。

### 2. 全球国家与省份路书库（Global Roadbook）
- 内置涵盖 **日本、中国（按省/直辖市细分）、韩国、新西兰、泰国、老挝、越南、新加坡、法国、意大利、捷克、挪威、英国、冰岛、美国、加拿大、秘鲁、约旦** 等地的精选拍摄基因预设。
- 一键自动映射当地空间尺度、光线条件、通行方式与场馆限制（如古建/寺庙/博物馆禁三脚架与闪光灯、暗夜保护区必带碳纤维脚架）。
- 支持**新增、编辑与删除**私人目的地预设，并可自由手写任意新国家或中国省份。

### 3. 多站跨城行程统筹 & 去重合并打包总清单
- **单日快照串联（Day 1 / Day 2…）**与**多站跨城行程一键配镜**均支持自动计算整趟行程的最大公约数底盘。
- 一键生成**出发前总行李箱去重合并装包清单**（自动合并共用 `67mm / 55mm` CPL 与 ND 滤镜、转接环、三脚架、闪光灯及电池块数）以及**逐天/逐站「随身带走 vs 酒店留守」核对单**。

### 4. 器材库、滤镜矩阵与实地复盘本
- 完整管理机身、镜头（含 `TAMRON 150-500mm` 默认排除与场景自动唤醒）、**镜头滤镜矩阵（UV / 共用 67mm·55mm CPL / ND 实时切换）**及三脚架/闪光灯附件（`Fotopro X-4CS II+42QJ`、`Ulanzi MT-33`、`神牛 iT32 + X5-S/X5-O`、`67→55mm 转接环`）。
- 内置**实地构图落差复盘本**，支持记录每次出行“主力真香”或“吃灰降权”体验并动态校准后续推荐权重。

## 📲 四端独立应用安装指南（PWA）

本项目内置运行时高分辨率矢量光圈图标、Web App Manifest 与 Service Worker 离线缓存内核，部署在 GitHub Pages 后即可在各平台安装为无浏览器边框、永久不过期的独立程序：

- **🍎 iOS / iPadOS（iPhone & iPad）**：使用系统 **Safari** 打开网页 → 点击「分享」→ **「添加到主屏幕」**，支持 iPad 分屏与飞行模式完全离线使用。
- **💻 macOS**：使用 **Safari** 打开网页 → 顶部菜单栏点击 **「文件」→「添加到程序坞 / 加入 Dock 中…」**，生成独立桌面应用窗口。
- **🪟 Windows 10 / 11**：使用 **Edge** 或 **Chrome** 打开网页 → 点击地址栏右侧 **「安装应用」** 图标。

## 🔗 跨端数据同步说明

为保障个人隐私与 100% 离线可用性，所有自定义修改均保存在当前设备的浏览器本地存储（`localStorage`）中。如需在 Mac、iPhone 与 iPad 之间同步记录，可使用第 4 标签页提供的两种方式：
1. **跨端同步短链（推荐）**：点击 **「🔗 生成跨端同步链接」** 复制链接，发送至手机/平板 Safari 打开即可一键「合并新增项」或「全量覆盖」。
2. **全量 JSON 备份 / 独立 HTML 导出**：支持一键导出 JSON 备份文本或内嵌全部个人数据的独立 `index.html`。
